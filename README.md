# Crystal Bastion Clicker (Prototype)

A lightweight browser prototype combining three loops:

- **Match-3**: swap adjacent crystals to create 3+ matches and generate Energy + Gold.
- **Tower Defense**: spend Gold on towers that automatically damage incoming enemies.
- **Idle Clicker**: click for manual Energy and buy auto-click upgrades for passive generation.

## Run locally

Because this is plain HTML/CSS/JS, you can open `index.html` directly in your browser.

## Core gameplay loop

1. Match crystals to generate resources.
2. Energy overflow spawns enemies.
3. Towers kill enemies to earn Gold.
4. Gold buys more towers and idle upgrades.
5. Survive increasing enemy pressure and wave growth.
